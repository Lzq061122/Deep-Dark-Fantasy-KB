# Deep Dark Fantasy KB

> **一个由朋友们共同建设的 AI 交流空间。**
>
> 分享正在折腾的项目、记录真实使用经验、讨论新工具和奇怪的想法。新手欢迎，半成品也欢迎。

这里最初只是一个整理 AI 使用经验的知识库。现在我们想把它做成一个更开放的小地方：**你可以来学习，也可以把自己的项目、发现、心得和问题留下来。**

没有“必须懂 AI 才能发言”的门槛。你可以只问一个问题，也可以放一篇长文、一个正在开发的 Demo，或者一段踩坑记录。

## 从哪里开始？

| 我想…… | 去这里 |
| --- | --- |
| **和大家聊一聊**，提问、分享发现、征求意见 | [Discussions 讨论区](../../discussions)（需由维护者先启用） |
| **展示自己在做的项目** | [项目展示区](projects/README.md) |
| **写一点工具使用心得 / 踩坑笔记** | [随手笔记区](notes/README.md) |
| **给知识库贡献文章、修改现有内容** | [参与指南](CONTRIBUTING.md) |
| **我是 AI 新手，想先学习** | [30 分钟上手 AI](START-HERE.md) |

> **第一次来？** 最简单的参与方式就是在 Discussions 发一条消息：“我最近在尝试什么 / 我遇到了什么问题 / 有没有人也在研究这个？”讨论区未启用前，可先通过仓库 Issues 或 Pull Requests 交流。具体操作看 [参与指南](CONTRIBUTING.md)。

## 这里欢迎分享什么？

### 🚀 项目展示

你的项目不需要已经完成：小工具、智能体、AI 应用、游戏开发、学习实验都可以。

可以分享做这个项目的动机、当前进度、截图、公开的代码或 Demo，以及希望大家给什么建议。

**入口**：[projects/](projects/README.md) · [项目介绍模板](templates/project-template.md)

### 📝 心得、发现与踩坑

“今天发现一个很好用的功能”“这个 Agent 为什么总卡在同一个地方”“这套 Prompt 没达到预期”——这些都值得记录。

不要求长篇大论，事实不确定时标注“尚未验证”即可。

**入口**：[notes/](notes/README.md) · [随手分享模板](templates/share-template.md) · [两分钟经验记录](templates/experience-note.md)

### 💬 提问与交流

可以讨论模型、AI Coding、Agent、MCP、工作流、项目设计，也可以互相推荐资料。没有基础问题羞耻，也不要求每次都拿出结论。

**入口**：[Discussions](../../discussions)（管理员启用后可用）

## 新朋友怎样加入？

1. **只是想交流**：登录 GitHub，直接到 Discussions 发表新话题或回复别人，不需要仓库写权限（需先启用该功能）。
2. **想分享自己的项目或心得**：先在 Discussions 发帖，想长期保存时再按[参与指南](CONTRIBUTING.md)添加 Markdown 页面。
3. **想一起长期维护**：通过 Pull Request 贡献内容；熟悉之后也可以联系维护者邀请为 Collaborator。协作者可以写入仓库，因此重要修改建议走独立分支和 PR，方便审阅与回退。

[参与指南](CONTRIBUTING.md) · [交流约定](COMMUNITY.md)

## 一起慢慢建设

- **不追求更新频率**：有发现再来写；想闲聊就闲聊。
- **真实比漂亮重要**：分享自己的经历，把事实、猜测和主观看法分开。
- **尊重每个人的作品**：转载请注明来源，别公开他人的私密项目或资料。
- **优先保护隐私**：上传前检查 API Key、Token、个人信息、截图和日志。

这是一个公开仓库。任何提交的公开内容都可能被其他人看到；涉及未公开项目时，请只分享你有权公开的部分。

**当前状态：社区空间初版（2026-10-26）**。现有页面已经支持多人贡献；Discussions 需要仓库管理员在 GitHub Settings → Features 中单独开启。

*这里是一群朋友交流 AI 的地方，不是考试，也不是作品评比。*
