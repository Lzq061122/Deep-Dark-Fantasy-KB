## 怎么参与？

- **想分享自己的内容**：在自己的文件夹内添加 Markdown 文件，或修改个人主页 `README.md`。
- **想交流想法**：可以在仓库 [Discussions 讨论区](../../discussions) 发帖（需要先由仓库管理员启用）。
- **想给对方的文章提建议**：可以发 Issue，或通过 Pull Request 提交修改。
- **第一次操作 GitHub**：查看 [参与指南](CONTRIBUTING.md)。

## 共同约定

1. 各自管理自己的内容；调整对方的文章时先沟通，尽量使用 Pull Request。
2. 项目可以是半成品，笔记可以不完整，遇到问题也可以直接记录。
3. 尽量注明哪些是亲测结果、哪些是推测或尚待验证。
4. 这是公开仓库，请勿提交密钥、Token、私人资料或未经授权公开的项目内容。
