# Deep Dark Fantasy KB

> **AdenineLeo × Ethan · 我们的 AI 交流、实践与知识共享空间**

这里是两个人一起折腾 AI 的小地方。可以分享正在做的项目、使用心得、踩坑经历，也可以共同补充面向新手的知识资料。

## 三个入口

| 区域 | 放什么？ | 入口 |
| --- | --- | --- |
| **Shared · 公共知识区** | AI 入门、工具与 Agent 基础、通用教程和资料 | [进入 Shared](Shared/README.md) |
| **AdenineLeo · Ade 的空间** | 个人项目、实战经历、心得与踩坑 | [进入 AdenineLeo](AdenineLeo/README.md) |
| **Ethan · Ethan 的空间** | Ethan 的项目、实验、经验和想法 | [进入 Ethan](Ethan/README.md) |

## 刚开始接触 AI？

可以直接从 [Shared / 30 分钟上手 AI](Shared/START-HERE.md) 开始。公共知识区中的文章欢迎两个人一起修订，发现解释不准确或版本过时，直接提出修改建议即可。

## 想分享点什么？

- **一个想法或正在做的项目**：放在自己的文件夹里，没完成也可以分享。
- **日常使用心得和踩坑**：放进自己的文件夹，写简短笔记就够了。
- **通用的 AI 解释、教程、方法**：放到 `Shared/`，两个人一起维护。
- **想聊天或征求意见**：用 [Discussions](../../discussions)（仓库管理员需先启用）或 Issues。

[如何参与](CONTRIBUTING.md) · [交流约定](COMMUNITY.md) · [项目模板](templates/project-template.md) · [心得模板](templates/share-template.md)

## 我们的小约定

1. 各自维护个人目录，`Shared/` 共同建设。
2. 不要求内容完整，也不要求一直更新。
3. 尽量区分亲测事实、个人判断和待验证信息。
4. 重要跨目录修改优先通过 Pull Request 沟通。
5. 本仓库公开可见，提交前请检查密钥、隐私资料和未经许可公开的项目材料。
