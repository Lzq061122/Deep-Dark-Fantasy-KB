## 阅读这份知识库时请记住

- **能用才算数。** 每篇尽量提供具体操作、示例与检查方法。
- **资料会过时。** 模型价格、额度、功能和界面经常变动；涉及这些内容时，以官方信息为准。
- **亲测和猜测分开。** 我会用「已观察」「经验建议」「待验证」区分事实、判断与未解决的问题。
- **不要盲信 AI。** 尤其是涉及钱、隐私、重要学习成果和代码修改时，必须自己验收。
