## 个人经验如何分享给别人？

我可能会先记下“今天遇到一个奇怪的 Agent 问题”，等之后找回日志、补上证据，再从中提炼出可以复用的方法。

- 原始经历保留在 **AdenineLeo**。
- 可复用的通用结论直接存入 **[Shared 经验库](../Shared/experiences/README.md)**；不需要改写成长篇教程。
- 还没核实的地方就直接写“待验证”。

这里也欢迎 AI 以外的项目和想法，不必把个人空间限制在一类工具里。
