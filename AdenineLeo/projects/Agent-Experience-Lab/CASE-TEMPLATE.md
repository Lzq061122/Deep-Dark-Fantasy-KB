# 通用经验条目模板

> 直接用于 `Shared/experiences/` 的简洁 Markdown 条目。不是文章模板，不要求照顾特定读者水平。

# 编号｜一句话可复用结论

**领域**：  
**来源项目或贡献者**：  
**核查状态**：来源记录 / 证据已核对 / 独立复现 / 待核实

## 可复用结论

这个结论可以指导未来哪类判断或行动？

## 触发场景

什么现象、条件或任务类型出现时，应想到这条经验？

## 机制与做法

为什么会发生？应如何设计、排查、检查或规避？

## 代表案例

从哪个实际事件中提炼？只写必要的事实，不复制私人原始记录。

## 边界与反例

哪些情况下不能直接套用？哪些条件会让结论失效？

## 证据

原始来源（最好是公开固定提交、文件或可核对报告）；已核对与尚未核对的部分分别标明。

> 已有同类条目时，优先增补案例与证据，不要重复制造条目。公开仓库中不写私人凭据、原始会话、内网地址或未经授权的第三方内容。
