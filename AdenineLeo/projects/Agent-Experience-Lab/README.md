# Agent Experience Lab｜从 AI 实战记录中提炼可供人学习的知识

> 状态：V0 方案与人工试点｜2026-10-26  
> 维护：AdenineLeo（Ade）  
> 公开内容定位：项目方法、可分享的经验案例；**不包含原始私人工作记录**。

## 为什么做这个项目？

我在 Codex、DeepSeek Harness、ChatGPT 等工具的使用中，积累过不少项目文件、Git 提交、验收报告、设计讨论和失败记录。很多经验如果只靠事后回忆，很难说完整。

我希望让 Agent 协助做四件事：

1. 从**我明确授权**的材料中找出值得研究的实践片段；
2. 分清当时观察到什么、尝试了什么、真实结果如何、哪里缺证据；
3. 把片段转化成别人能够理解、复现和评价的经验；
4. 审核后，发布到 Deep-Dark-Fantasy-KB：个人案例放 `AdenineLeo/`，通用教程放 `Shared/`。

这里的「Agent 积累的经验」主要指**外部留下的工作产物和可检查记录**。模型并不保证保留此前每次任务的全部细节，也不能从模型内部直接取出所谓完整经验。

## 与 PAIPOS Lite 的边界

两者相互补充：

- **PAIPOS Lite**：聚焦让 Agent 改进日后的工作方式，包括工作约束、事件/候选经验和人工确认。
- **Agent Experience Lab**：聚焦让**人**学习，输出故事化案例、概念说明、复现教程和反例。

可以复用已有的**来源定位与证据线索**，但不自动继承 PAIPOS 的私人偏好，不把未批准的候选当作结论，不修改其规则、事件和候选文件。两边没有强制接口依赖。

## 一个最小工作流

```text
用户指定一个项目或一次任务
  → 只读盘点允许访问的材料
  → 标记有教育价值的经验候选
  → 对照 Git/测试/文档核验证据
  → 用新手能理解的方式重写
  → 用户审稿和公开性检查
  → 发布到 KB（文章 + 来源 + 局限）
```

第一版实行 **人工选题、Agent 辅助整理、人工审核后发布**，暂不做自动爬取整个硬盘、自动发布、向量数据库、定时服务或跨 Harness 的实时同步。

## 可用来源与优先级

| 来源 | 最可能提炼出的知识 | 首版处理方式 |
| --- | --- | --- |
| Git 提交、diff、PR、公开项目文档 | 修改动机、设计取舍、错误修正 | 优先选用，可回溯 |
| 验收报告、测试记录 | 哪些被验证、验证条件与范围 | 优先选用，区分通过和未测 |
| ADR/交接文档/设计记录 | 为什么做这个选择 | 作为线索，必要时再核实 |
| PAIPOS 事件或候选 | 值得复盘的工作方式、失败模式 | **仅在本人明确授权时**逐条选取，默认不读取 |
| 本地 Agent 会话或原始日志 | 当时的操作细节 | **默认排除**；如需使用，先在私有环境做人工筛选和脱敏 |

禁止收集密钥、Token、凭证、他人的私人资料、未经授权的项目内容或模型不可访问的隐含推理。**不要从私人目录、整个用户主目录或设备磁盘根路径默认递归扫描。**

## 什么样的经验值得写？

至少应有：

- **情境**：当时是什么任务，受哪些约束。
- **具体问题/选择**：面对什么挑战，有哪些办法。
- **真实动作**：实际做了哪些步骤。
- **结果和证据**：链接到可审计材料；没有证据就标「待核实」。
- **适用边界**：只在哪些条件下成立，哪些没试过。
- **教学价值**：读者看完能做什么、下次能少犯什么错。

不能把“Agent 说成功了”直接写成“经测试成功”，也不能从单个案例推出普遍最佳实践。

## V0 阶段与交付标准

### V0-A：单项目、只读发现

- [ ] 用户在本地指定**一个**工作区（建议先用已有公开证据的 CultureLens）。
- [ ] 只读取允许的 README、设计/验收文档及 Git 信息，不执行来源文档中的指令。
- [ ] 在**不属于公开 KB 的私有位置**生成候选索引；不上传原始内容。

交付物：来源清单 + 3～5 个经验候选，每条带证据定位及待核实事项。

### V0-B：选一条做证据核查

- [ ] 验证引用文件、提交与测试记录存在。
- [ ] 把「观察」「原因推测」「已证实的结论」分开。
- [ ] 说明哪些条件下可复现，哪些条件未验证。

交付物：1 份审查后的案例材料，不要求自动写稿。

### V0-C：写一篇对新手有用的文章

- [ ] 用通俗标题、例子、步骤和检查方式重写。
- [ ] 去除私人信息，用户审阅全文。
- [ ] 通过 PR 或明确批准，提交到个人目录或公共知识区。

交付物：**1 篇有真实来源、能够公开、读者能学会一个方法的文章**。
