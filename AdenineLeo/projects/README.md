## 我希望以后怎么记录项目？

这里每个项目都可以逐渐积累以下几类内容，**有材料再补，不必一次写完**：

1. **项目为什么存在**：我想解决什么问题、为什么觉得它有意思。
2. **已确认的进展**：具体完成了什么，最好有对应提交、演示或测试结果。
3. **重要的设计选择**：为什么选择 A 而放弃 B，以及当时的约束。
4. **踩坑与未解问题**：哪些是亲自观察到的，哪些仍然只是猜测。
5. **可以复用的经验**：值得提炼到 [Shared 公共知识区](../../Shared/README.md) 的方法。

如果一个项目需要详细介绍，可以以后在这里建立同名 Markdown 页面；目前直接链接原仓库，避免重复维护。
