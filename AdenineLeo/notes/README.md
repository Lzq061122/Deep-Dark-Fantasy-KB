# Ade 的随手记录区

这里允许**任何时候、任何主题**的想法、心得、使用感受、奇怪的发现和暂时没有结论的问题。不限于 AI、编程或某个项目，更不需要先完成一项任务。

**原则：先记下来，再决定要不要深入整理。**

## 最快的记录方式

直接告诉具有仓库访问权限的 Agent：

> 记一下：我觉得这次的设计讨论虽然想了很多，但核心问题还是没被解决。

它应该直接把这段内容整理成简短的个人笔记，按月追加到 `AdenineLeo/notes/YYYY-MM.md`，不需要问你“项目路径是什么”“有测试证据吗”或“要不要写成文章”。

如果只是想保留原话，可以说：

> 原话记下来：……

这时不要擅自改写意思。

## 记录格式

按日期存入同一个月度 Markdown 文件。例如：

```markdown
## 2026-10-26｜一个关于复杂方案的想法

今天我觉得……

- 类型：个人想法（未验证）
- 关联：有的话可以加，没有就留空
```

这是示意，不要求每次都有标题、关联项目或完整的字段。**重要的是能够随时保存，且以后找得到。**

## 什么时候放入 Shared？

当一条想法逐渐变成**有代表性、可跨项目复用的判断或方法**时，可以由 Agent 另行提炼到 [Shared 通用经验库](../../Shared/experiences/README.md)。但并不强迫每条心得都这么做，也不要求写成教程。

个人心得可以记录“我当时怎么想的”，通用经验则应写清适用范围和依据，不把个人感受说成普遍事实。

## 公开性与隐私

本目录属于公开 GitHub 仓库。要记录的内容若涉及私人关系、聊天、凭据、内部资料或任何不适合公开的细节，**不要直接提交这里**；先存到自己授权的本地私有笔记位置。需要同步时再决定安全的摘录范围。
