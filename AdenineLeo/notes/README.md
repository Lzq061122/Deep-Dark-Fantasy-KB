# Ade 的随手记录区

这里用来保存尚未整理成正式教程的想法、实验观察和工具体验。

**原则：先记下来，之后再整理。** 我不需要每次都写出一篇完整文章，也不必回忆出所有命令和细节。

## 目前已有的经验记录

- [Agent 与项目开发：四组踩坑及待验证问题](../06-field-notes/01-lessons-and-open-questions.md) —— 包含多 Agent 修改代码、复杂模型研究、上下文交接、工具兼容性等话题。
- [两分钟经验记录模板](../templates/experience-note.md) —— 有问题时先存下事实、日志线索和解决状态。

## 以后记一条新经验，可以只写这些

```text
今天想做什么：
使用的工具或模型（知道就写）：
实际发生了什么：
结果：成功 / 失败 / 未确认
有没有截图、提交或日志：
我现在怎么理解它：
下一次要检查什么：
```

重要的是区分**看到的现象**与**对原因的猜测**。缺少证据就标注“待核实”；补齐证据后再把记录升级为文章。

## 从个人记录变成公共教程

```text
个人尝试
   ↓
保留当时事实、环境与证据
   ↓
再现或补充核查
   ↓
抽取对别人也有用的方法
   ↓
整理到 Shared 公共区
```

例如，个人笔记里记录“两次前端重构让我不确定代码有没有丢失”；公共教程则可以讲“怎样比较两个 Git 提交、怎样安排多个 Agent 的独立工作区”。

这样既保留个人经历，又不必把未经验证的推测当作通用知识。
