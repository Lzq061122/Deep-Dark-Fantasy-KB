# 随手笔记区｜小发现也值得留

这里收集参与者的使用心得、想法、失败记录和对 AI 工具的评价。**不要求完整，不要求技术深度**。

你可以分享：
- 今天第一次让 AI 帮你完成了什么任务；
- 哪个工具的操作流程让你困惑；
- 一个你喜欢的提示词或工作流；
- 一次 Agent 报错、解决过程或至今无解的尝试；
- 你对某个功能或设计的观点。

## 两种分享方式

**想讨论、想得到回复**：优先用仓库 Discussions，交流更方便。

**想留一份可持续修改的文字**：建立 `notes/<你的GitHub用户名>/<日期>-<标题>.md` 文件，例如：

```text
notes/
  your-github-name/
    2026-10-26-my-first-ai-project.md
    2026-10-27-agent-debugging.md
```

可以复制 [随手分享模板](../templates/share-template.md)，也可以自由书写。尚未核实的原因请明确标出。

公开发表前检查是否涉及他人隐私、未公开的项目细节、密钥或账号资料。
