# 项目展示区｜大家最近在折腾什么？

这里用来展示大家正在做、做过或者准备尝试的 AI 项目。**还没做完也可以发。** 分享目标、进度、问题和想法，远比一张漂亮但没有解释的截图有用。

## 项目列表

欢迎在这里增添你自己的项目。新建项目时，可以在下面的表格里加一行，并链接到项目介绍页。

| 项目 | 作者 | 一句话介绍 | 状态 |
| --- | --- | --- | --- |
| 等待你的第一个项目 | — | 用 [项目模板](../templates/project-template.md) 开始 | 招募中 |

> 上面一行只是占位，不代表有真实项目。正式添加项目后可删除。

## 怎么投稿？

- **还不确定项目方向？** 可以先去 Discussions 的项目展示或求助话题聊一聊。
- **已经在做了？** 在 `projects/<项目简称>/README.md` 新建一个页面，复制 [项目介绍模板](../templates/project-template.md) 作为起点，再向此表格添加入口。
- **项目仓库在别处？** 没必要把代码复制进来。可以放原仓库链接（前提是你有权公开它）、截图、Demo 及简短说明。
- **想找队友？** 写明需要什么帮助、项目当前状态和联系渠道；不建议公开私人联系方式，可通过 GitHub Discussions 或个人主页建立联系。

不限制项目类型：AI 应用、学习工具、编程 Agent、小游戏、自动化脚本、实验性作品都可以。
