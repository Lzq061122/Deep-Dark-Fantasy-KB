# E-03｜空值不一定代表“用户没有处理过”

**领域**：状态管理 / 人工编辑 / AI 重新生成  
**来源项目**：CultureLens · Ade  
**核查状态**：公开代码与最终验收说明已对照；本次未重新执行端到端流程。

## 可复用结论

**内容值**与**用户操作状态**不能简单混为一谈。用户主动清空字段是一次操作；如果系统仅凭字段为空判断“尚未处理”，后续自动填充可能覆盖用户意图。

## 触发场景

- AI 生成的文本可由人工编辑、忽略、采纳或清空。
- 再次生成时需要保护人工处理过的内容。
- 前端输入框与数据库存储的内容可能不一致。

## 操作原则

- 用独立的状态表达用户是否以及如何处理过内容。
- 明确再生成操作哪些字段可以更新、哪些必须保留。
- 覆盖测试“主动清空 → 再生成”和“从未处理 → 再生成”两条路径。
- 检查 UI 显示、保存状态和导出行为是否一致。

## 代表案例

CultureLens 集成审查记录：清空字幕的正式译文后，状态错误地被当成未审核，再生成时模型文本被填回。后续将人工清空标为已编辑，保留空值并禁止缺译文导出。最终验收还识别并修正了清空后输入框错误显示草稿的独立 UI 问题。

## 边界

某些产品的设计语义确实允许“清空 = 恢复自动默认值”，但必须明确规定和展示，不能由模糊的空值判断暗中决定。**不要求固定采用三态状态机**，状态集合取决于业务契约。
