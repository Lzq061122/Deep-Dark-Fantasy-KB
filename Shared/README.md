## 什么内容适合放在 Shared？

- 适合双方共同学习的 AI 基础知识
- 可复用的教程、工作流、参考资料和方法
- 对工具概念的中立说明与需要共同维护的指南

个人项目、主观心得和个人踩坑，建议分别放在 [AdenineLeo](../AdenineLeo/README.md) 或 [Ethan](../Ethan/README.md) 的空间里。涉及个人经历的文章如果提炼出了通用经验，也可以单独再写一篇放到 Shared。

**规则很简单**：公共资料可以共同改，跨人内容的重要修改先沟通；记得核查可能过时的功能描述。
