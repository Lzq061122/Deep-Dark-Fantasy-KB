## 怎样维护公共文章？

1. **尽量有读者对象**：标出这是给新手还是已经会编程的人。
2. **有可操作的例子**：尽量提供步骤、检查点、适用条件，而不只是抽象定义。
3. **区分事实与判断**：价格、功能和型号等可能过时；必要时标明验证日期和来源。
4. **个人经验先留在个人空间**：要成为公共教程，尽量提炼出可重复的步骤及适用边界。
5. **小修改也欢迎**：发现一个错别字、一个失效链接，直接通过 PR 修正即可。
